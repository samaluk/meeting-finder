How it decides

Not every invitation
is an all-or-nothing decision

■

The people you need

Required participants must meet their attendance rule. If they can’t, the time is blocked. A high score never overrides that.

□

The people you’d like

Optional participants improve coverage when they can join. Give each person a relative weight to reflect what matters.

The things we don’t know

An unreadable calendar is unknown, never free. The uncertainty sits next to the conflicts instead of hiding behind a promise.

When nothing fits

Sometimes nothing fits,
and you’ll know why

See blocked alternatives and the people or rules that block them. Adjust the conditions yourself. Meeting Finder never quietly relaxes a requirement.

It reads free/busy information. It doesn’t create events, send invitations or messages, assume conflicts can move, or store calendars in your browser.

Setup guide ↗
Bun and mise 
git clone https://github.com/samaluk/meeting-finder.git
cd meeting-finder
mise install
mise run install
bun run build
bun run start -- serve --demo --port 4310

Then open 127.0.0.1:4310. Demo mode makes no Google calls.
